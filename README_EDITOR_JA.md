# Android版ゲームエディターの使い方

このZIPは前回のAndroid更新内容を含む、エディター追加版（2.0.a2 / versionCode 30）です。

## エディターを開く

選曲画面で曲・譜面を選び、**メニュー → ゲームエディター**を開きます。

- **選択中の譜面を編集**：既存の譜面を編集します。初回の取得時に投稿パスワードを確認します。端末に下書きが残っている場合はそれを復元します。
- **選択中の譜面を基に新規作成**：別の新しい譜面として作成します。基の譜面は変更しません。
- **空の譜面から新規作成**：歌詞から新しい譜面を作ります。

新規作成は、最初は端末だけの下書きです。「仮保存」または「本投稿」で初めてサーバーに登録します。同じ曲の未登録下書きは1つ、既存の譜面下書きは譜面IDごとに保存します。再び同じ作成・編集を開くと復元されます。

## 歌詞と時刻を編集する

1. **歌詞 → 歌詞を挿入**で歌詞を入力・貼り付けします。カーソル位置に追加されます。漢字・カタカナのひらがな変換も利用できます。変換前の文も表示します。固有名詞や特殊な歌い方は読みを手直ししてください。
2. 動画を再生し、歌に合わせて**時刻を付ける**を押します。時刻が付き、次のかな文字へカーソルが進みます。小さいかな・長音・句読点等は自動移動時に飛ばします。
3. **ノーツ**をONにし、フリック対象を指定します。再生中は現在時刻に近い文字、停止中は選択文字を対象にします。
4. **取り除く**で前の時刻、または前のフリック指定を取り除けます。**Undo / Redo**で編集操作を取り消す・やり直すことができます。

歌詞欄では以下の操作ができます。

| 操作 | 動作 |
| --- | --- |
| タップ | カーソル移動 |
| ダブルタップ | その文字の時刻に動画をシーク |
| 長押し | 文字・時刻・フリック指定を直接編集 |
| ドラッグ | 歌詞を上下左右にスクロール |
| ピンチ | 拡大・縮小 |

フリック対象はピンク色、その他は薄い黄色です。時刻が付いた文字には時刻を表示し、通過した文字は赤く表示します。青枠が選択中の文字です。

動画のシークバー、−3秒 / ＋3秒、0.1〜2.0倍速を利用できます。前後移動は速度に応じて距離も変わります。

**歌詞・タイムタグ全文を編集**では、テキストを直接編集できます。タイムタグは `[00:01:23]` が表示用、`[00:01.23]` がフリック対象です。最後の2桁は1/100秒です。時刻未設定のフリック指定は端末保存時に `[**:**.**]` で保持します。

UTF-8のテキストファイルの読み込み・書き出しに対応しています。Androidのファイル選択画面から選べます。初音ミクWikiのページURLから歌詞を取得する機能もあります。ページの構造によって取得できない場合はコピーして挿入してください。

## 譜面設定と試しプレイ

**メニュー → 譜面情報・難易度・速度・オフセット**で、難易度（★1〜10 / FULL）、Creator、説明、ノーツ速度（50〜500）、譜面全体のオフセットを変更します。難易度の参考値も表示します。

**メニュー → 打刻補正の設定**は、タイムタグを打つ時の補正です。初期値は最新iPhone版と同じ−115msと0.07です。

```
打刻時刻(ms) = 再生位置(ms) + 係数 × (1 − 再生速度) × 1000 + 打刻補正(ms)
```

譜面全体のオフセットとは別の設定です。フリック指定を再生しながら付ける際は、譜面オフセットを考慮して対象文字を選びます。

**試しプレイ**は、編集時の再生位置から開始します。再生位置、再生速度、オートプレイを操作できます。試しプレイのメニューから速度・譜面オフセットを調整できます。戻ると編集画面へ再生位置・速度・オフセットが反映されます。

試しプレイは通常のスコア、プレイ回数、プレイ済み履歴を保存・送信しません。ゲージが0でも終了しません。動画終了時は編集画面へ戻ります。FULL設定でも個別のフリック対象が指定されている場合は、それらの指定を試すモードで再生します。

## 保存と投稿

| 操作 | 保存先・公開状態 |
| --- | --- |
| 端末に保存 | この端末の下書きだけを更新 |
| 編集中としてサーバーに仮保存 | iPhone版と同じ編集中の譜面として保存 |
| 本投稿 | 通常の公開譜面として登録・更新 |
| 下書きを破棄 | 端末の下書きを削除して戻る。サーバーの譜面は残る |
| データベースから削除 | パスワードと確認後、サーバーの譜面を削除 |

下書きは10秒ごと、試しプレイ前、画面を離れる時にも端末へ保存します。復元用データは原子的なファイル書き込みを使用します。端末の下書きには歌詞・譜面情報・カーソル・再生位置・打刻補正を保存し、投稿パスワードは保存しません。

新規投稿ではパスワードを設定します。このパスワードは以後の編集・削除に必要です。既存譜面の投稿・削除では、その譜面のパスワードを入力します。公開済みの譜面を編集中の状態に戻す仮保存は行わず、端末保存または本投稿を使う構成です。

投稿成功後は端末の下書きを削除して選曲画面へ戻ります。仮保存した譜面を続けて編集する場合は、選曲画面からその編集中譜面を選んで開いてください。通信失敗時は端末の下書きを残します。新規投稿で応答を受け取れなかった場合、サーバー側だけ登録が完了している可能性があるため、再送前に選曲一覧を確認してください。

iPhone版では編集中の譜面を閉じる際に自動で仮保存しますが、Android版では「仮保存 / 端末保存で戻る / 編集を続ける」を選べるようにしました。

本投稿の前に、かな文字の時刻、フリック対象、時刻未設定のフリック指定、時刻の逆転、オフセット適用後の負時刻をチェックします。

## 移植範囲と検証

iPhoneのEditorView / EditorMenu / EditorSettings / SpoonClassを参考に編集機能を実装しました。EditorGame相当の試しプレイはAndroidの既存ゲーム画面を再利用しています。UILabelによる歌詞表示はAndroidのCanvas描画へ、iOSファイル操作はAndroidのファイル選択画面へ置き換えました。

漢字の読みはAndroidにiOSと同じ変換APIがないため、端末内で動くKuromoji IPADIC 0.9.0を使用します。iPhone版と読みが異なる場合があります。音声・歌詞を外部の変換サービスへ送る実装はありません。ライセンスはエディターメニューの「ライセンス」で確認できます。

デバッグAPKのビルドと単体テスト16件（既存5件＋エディター11件）が成功しています。実機・エミュレーターでのUI操作、動画再生、実サーバーへの投稿・削除は未確認です。開発作業中に実サーバーへ投稿・削除は行っていません。

### 実機で確認する順序

1. 空の新規譜面を作成し、歌詞挿入・ひらがな変換・打刻・フリック指定・Undo/Redoを確認する。
2. 端末保存して閉じ、再度開いて歌詞・時刻・カーソル・設定が復元されることを確認する。バックグラウンド復帰でも確認する。
3. テキストを書き出し、再読み込みして同じ譜面になることを確認する。
4. 試しプレイの開始位置、速度変更、シーク、オートプレイ、試しプレイからの戻りを確認する。通常スコアやプレイ回数が増えないことも確認する。
5. 試しプレイで速度・オフセットを変え、編集画面に反映されること、二度開いてもオフセットが二重加算されないことを確認する。
6. テスト用譜面を仮保存し、自分の編集中譜面として一覧に出ること、パスワードを使って再編集できることを確認する。
7. テスト用譜面を本投稿し、通常ゲームで同じ時刻・フリック対象になることを確認する。
8. 通信失敗時の下書き保持、パスワード誤りの表示、削除時の確認と結果を確認する。

接続先は前回同様、元のAndroid版のサーバーです。最新iPhone版内のローカルIPは使用していません。サーバーAPIの対応状況は確認してください。
