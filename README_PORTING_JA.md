# NicoFlick Android 更新版（2.0.a2）

## このプロジェクトについて

iphone_old / android_old / iphone_new の3プロジェクトを比較し、最新iPhone版の変更を既存Android版に移植しました。既存のKotlin・Android画面・ExoPlayerを基礎にしています。XcodeのPodfile等は移植対象にしていません。

## 反映した変更

| 項目 | Android版での変更 |
| --- | --- |
| お気に入り | 曲単位のお気に入りと曲別件数、新しい並べ替え・アイコン |
| 譜面の評価 | like / love / dislike、プレイ履歴・スコアによる評価条件、評価優先表示 |
| データ移行 | 旧譜面お気に入りから曲お気に入りへ変換。旧評価は互換マーカーとして保持 |
| 通信 | 新しい曲・評価カウント取得API、種類別の差分送信、送信中に増減した値を保持する応答処理 |
| 練習 | シーク、0.1〜2.0倍速、オートプレイ、巻き戻し後の再判定、通常スコア保存の抑止 |
| ゲーム処理 | フレーム同期、表示外ノーツのミス判定、かな判定の統一、再判定による二重加点の防止 |
| 表示・設定 | キーボード位置に合わせた動画表示、オフセット表示設定、ソート表示、曲番号選択 |
| 初回案内 | 初回の名前登録案内、プレイ後の名前登録提案 |
| 履歴 | プレイ開始履歴、途中終了時のプレイ回数条件、曲単位スコア集計 |
| 譜面エディター | 歌詞の挿入・編集、時刻付け、フリック対象、Undo/Redo、拡大縮小、試しプレイ、端末保存・仮保存・本投稿・削除 |

iOSの画面構成はAndroidの既存画面・ダイアログに合わせて実装しています。見た目が完全に同じという意味ではありません。

譜面エディターとエディター設定を追加しました。操作方法は `README_EDITOR_JA.md` を参照してください。ユーザーカードは追加していません。UIKit/SceneのライフサイクルやReplayKit等のiOS固有処理はそのまま移植せず、Androidのライフサイクル・動画再生処理を使用しています。

## サーバー設定と互換性

接続先は元のAndroid版の `https://main-timetag.ssl-lolipop.jp/nicoflick/nicoflick.php` を維持しました。最新iPhoneプロジェクト内の開発用ローカルIPはコピーしていません。設定箇所は `app/src/main/java/com/mizushiki/nicoflick_a/Activity__Main.kt` のGLOBALです。

サーバーには新しいAPIへの対応が必要です。エディターはiPhone版と同じ `level-passCheckz` / `levelz-insert` / `level-update` / `level-delete` も使用します。取得は `musics`、`level-PcLcCtSt`、`music-Fc`、送信は `playcount-add`、`likecount-add`、`dislikecount-add`、`musicfavorite-add` を使用します。オンラインのサーバー互換性・実データの送受信はこの環境では確認していません。

未送信差分は端末に保持し、成功応答があった差分だけを取り除きます。旧favorite送信キューを新しいlikeとして送る処理は入れていません。旧お気に入りの対応先がまだ取得できない場合は移行を保留し、データ取得後に再試行します。既存ユーザーID、スコア、設定を引き継ぐ構成です。

## 開き方・ビルド

1. ZIPを新しいフォルダーに展開し、Android Studioでプロジェクトのルートを開きます。
2. Android SDK Platform 33を用意し、Gradle同期を実行します。必要なSDKはAndroid Studio側でインストールしてください。
3. デバッグ版をビルドし、端末またはエミュレーターで確認してください。

使用構成はAGP 7.4.2、Gradle 7.5、Kotlin 1.6.21です。JDK 17で確認しました。minSdk 24、compileSdk/targetSdk 33は元のAndroid版を維持しています。

```sh
./gradlew assembleDebug testDebugUnitTest
```

Windowsでは `gradlew.bat assembleDebug testDebugUnitTest` を使用します。

ExoPlayer 2.11.3を維持し、取得先を同グループだけに限定したAlibaba Mavenミラーへ調整しました。その他の依存関係はgoogle()/mavenCentral()から取得します。Kotlin標準ライブラリーのバージョンをプラグインに揃えました。漢字の読み変換にはオフラインのKuromoji IPADIC 0.9.0を追加しました。辞書を含むためAPKのサイズは増えています。ライセンスはエディターメニューから確認できます。

このZIPに端末固有のlocal.properties、ビルド生成物、IDEキャッシュは含めていません。実行用APKはAndroid Studioで生成してください。

- 更新後ソースで `assembleDebug testDebugUnitTest` 成功。
- 単体テスト16件、失敗0件・エラー0件（既存5件＋エディター関連11件）。
  - 送信中に変更されたカウントが成功応答後も残ること
  - 取り消されたお気に入り差分が送信対象に残らないこと
  - 練習中の再判定でスコアが二重加算されないこと
  - ゲージが負数にならないこと
  - 手入力とオートプレイが同じかな正規化を使うこと
- エディター関連では、譜面の読み書き、オフセット、未打刻ノーツ、Undo/Redo、打刻補正、投稿パラメーターのエンコード、漢字の読み変換、Wiki歌詞抽出を確認。
- APKにひらがな変換の辞書8ファイルとライセンス文書が含まれることを確認。

実機・エミュレーター上の操作、実際の動画再生、オンラインAPIとの連携は未確認です。ビルド成功はそれらの動作保証を意味しません。

## 実機での確認項目

既存アプリを上書きする前に、必要なユーザー情報・スコアを控えてください。署名が異なるAPKでは同じアプリとして上書きできないため、従来の署名設定を使ってください。

- 旧版データを持つ端末で、ユーザーID・スコア・設定が残り、旧お気に入りが曲お気に入りに移ること。
- 新規インストールで名前登録案内が表示され、名前が正しく保存されること。
- 曲お気に入りの追加・取り消しと各評価、ダイアログのキャンセル、並べ替え結果を確認すること。
- 未プレイ譜面や未保存スコアで評価条件が適用されること。
- オフライン中の変更、再接続、送信中の追加変更、取消の負差分がサーバーと一致すること。
- Android標準キーボード・専用キーボードで通常プレイし、密集ノーツ、ミス、判定タイミングを確認すること。
- 練習中に前後へシークし、巻き戻し再判定で得点が増殖しないこと。シーク後最初の入力より前のノーツ処理も確認すること。
- オートプレイと0.1・1.0・2.0倍速、ゲージ0時の練習継続、練習結果が通常スコアに保存されないこと。
- 小さい画面・大きい画面で動画・ノーツ・キーボードが重ならず、設定切替が反映されること。
- リトライ、メニュー、バックグラウンド復帰、結果から選曲へ戻る操作で二重再生・二重処理がないこと。
- 編集中譜面の表示条件、タグ、@sm範囲検索、お気に入り優先の選曲結果を確認すること。

テストは `app/src/test/java/com/mizushiki/nicoflick_a/` 内の `V2000PortTest.kt` と `EditorDocumentTest.kt` にあります。
